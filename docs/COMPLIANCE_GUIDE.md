# Basalt Framework — 等保三级测评指引

> **标准**：GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》第三级  
> **系统**：Basalt Framework v2.2.0 | by Genesiu  
> **说明**：本文档供等保测评师现场核查使用。系统已内置 WebUI 等保指引页面（菜单「等保指引」），可直接跳转到对应功能。

---

## 一、身份鉴别（8.1.4.1）

### a) 用户标识唯一性
- **WebUI 位置**：菜单「用户管理」→ 查看用户列表
- **API 验证**：`GET /api/v1/users/` → `username` 字段均为唯一值
- **代码位置**：`models/system.py` → `User.username` 有 `unique=True` 约束

### b) 鉴别信息复杂度
- **WebUI 位置**：菜单「安全策略」→ 查看 `强制口令复杂度` 开关
- **现场演示**：创建用户时设弱密码 → 系统拒绝并提示复杂度要求
- **支持字符**：大小写字母 + 数字 + 特殊字符（`!@#$%^&*()_+-=~.,?`）

### c) 鉴别信息定期更换
- **WebUI 位置**：菜单「安全策略」→ 查看 `口令有效期` 配置（默认 90 天）

### d) 登录失败限制
- **WebUI 位置**：菜单「安全策略」→ 查看 `登录失败锁定次数` 和 `锁定时长`
- **现场演示**：连续输错密码超过阈值 → 账号被锁定

### e) 默认账户口令修改
- **现场演示**：使用默认密码登录 → 返回 403 + 强制改密页面
- **WebUI 位置**：菜单「用户管理」→ 创建新用户后首次登录验证

### f) 会话超时
- **WebUI 位置**：菜单「安全策略」→ 查看 `会话超时` 配置
- **前端验证**：登录后静置超时 → 自动跳转登录页

### h) 多因素认证（MFA）
- **WebUI 位置**：菜单「个人资料」→ TOTP 绑定区域
- **绑定流程**：扫码 → 输入 6 位验证码 → 验证通过后才确认绑定
- **API**：`POST /totp/setup` → `POST /totp/verify`（两步验证）

### i) 密码不含用户名
- **现场演示**：用户名 `testuser`，密码含 `testuser` → 系统拒绝

### j) 密码历史不重复
- **现场演示**：修改密码后尝试改回旧密码 → 系统拒绝（检查近 5 次历史）

## 二、访问控制（8.1.4.2）

### a) 最小权限
- **WebUI 位置**：菜单「角色与权限」→ 查看每个角色的权限节点
- **现场演示**：普通用户访问管理接口 → 返回 403

### b) 三员分立
- **WebUI 位置**：菜单「角色与权限」→ 确认存在三个预置角色
- **权限矩阵**：
  - sysadmin：`policy:manage`, `user:manage`, `role:manage`, `audit:view`, `audit:export`
  - auditadmin：`audit:view`, `audit:export`
  - ordinary：无预置权限

### g/h) 安全标记（MAC）
- **WebUI 位置**：菜单「角色与权限」→ 查看 `max_clearance` 字段
- **API**：`GET /api/v1/roles/security-levels` → 返回安全等级定义

---

## 三、安全审计（8.1.4.3）

### a-b) 审计记录覆盖与完整性
- **WebUI 位置**：菜单「审计日志」→ 查看审计记录列表
- **字段**：时间 / 操作人 / 动作 / 来源 IP / 状态 / 详情

### c) 审计日志防删改
- **验证方式**：命令行执行 `DELETE FROM audit_logs` → SQLite 触发器拦截报错
- **代码位置**：`main.py` → `audit_logs_no_update` / `audit_logs_no_delete` 触发器

### f) 审计导出
- **WebUI 位置**：菜单「审计日志」→ 点击 `导出 CSV` 按钮

---

## 四、入侵防范（8.1.4.4）

### c) 管理终端限制
- **WebUI 位置**：菜单「安全策略」→ `IP 访问控制白名单` 区域
- **现场演示**：从非白名单 IP 访问管理接口 → 返回 403

---

## 五、数据安全（8.1.4.7-10）

### 存储保密性（8.1.4.7）
- **验证方式**：查看数据库中 `encrypted_phone` 等字段为密文
- **代码位置**：`core/crypto.py` → `AESCipher`（AES-256-GCM）

### 数据备份与恢复（8.1.4.9）
- **WebUI 位置**：菜单「备份管理」→ 查看/修改备份策略
- **功能**：开关调度、执行时间、备份目录、保留天数、手动触发
- **验证方式**：`ls -la backups/` → 查看 `.gz` 备份文件 + `.sha256` 校验码

### 敏感数据释放
- **现场演示**：停用用户 → 查看数据库中 `totp_secret` 和 `encrypted_phone` 已清空

## 六、安全管理中心（8.1.5）

### 三员职能
- **系统管理员**：菜单「用户管理」「角色与权限」「安全策略」「备份管理」
- **审计管理员**：菜单「审计日志」→ 查看 + 导出
- **安全管理员**：菜单「角色与权限」→ 安全等级管理

### WebUI 菜单结构
| 菜单分组 | 菜单项 | 功能 |
|----------|--------|------|
| 用户与权限 | 用户管理 | 创建/编辑/停用用户 |
| 用户与权限 | 角色与权限 | RBAC + 安全标记 |
| 安全与审计 | 安全策略 | 等保基线参数 + IP 白名单 |
| 安全与审计 | 审计日志 | 查看/导出审计记录 |
| 运维与合规 | 备份管理 | 备份调度配置 + 手动备份 |
| 运维与合规 | 等保指引 | 条款→功能映射（本页） |
| 个人 | 个人资料 | 改密 + TOTP 绑定 |

## 快速验证清单（测评师用）

| # | 验证项 | 操作 | 预期结果 |
|---|--------|------|----------|
| 1 | 弱密码拦截 | 创建用户密码 `123456` | 返回"密码复杂度不足" |

| 7 | IP 白名单 | 非白名单 IP 访管理接口 | 返回 403 |

| 10 | 备份功能 | 菜单「备份管理」→ 立即备份 | 生成 .gz + .sha256 文件 |
